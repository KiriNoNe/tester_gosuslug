Цель разработки программы: Создание программного обеспечения, которое автоматизирует процесс мониторинга и оценки доступности сервисов МВД, предоставляемых через портал государственных услуг. Это включает в себя проверку и анализ возможности предварительной записи на прием в отделениях внутренних дел, а также формирование отчетов о доступности услуг.
***
Для правильной работы программы нужно предварительно установить браузер firefox, но программа может не работать с новыми версиями браузера. Для решения проблемы стоит либо установить более старую версию браузера либо более новую версию geckodriver и заменить его в папке.
